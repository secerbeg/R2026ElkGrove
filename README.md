# Elk Grove Roseville Schedule

The homepage is `index.html`. Draft games, groups, playoffs and field map are embedded. **Published & scores** requests the latest public MLS Assist schedule every time that tab is opened for the first time and whenever **Refresh published schedule** is selected.

## Publication status rules

- **Direct live feed succeeds:** show whatever it returned, including zero games, and display the check time and the source's `synced_at` separately.
- **Direct feed blocked or unavailable:** try `data/published-schedule.json` generated by this site's scheduled GitHub Pages build. Use it only when `_site_fetched_at` is no older than 3 hours. Label it "Latest site sync" with retrieval time.
- **Neither available:** show "Cannot retrieve published schedule" and the actual check time. **Never present the October 14 snapshot as a current update.** Draft games remain accessible.

## GitHub Pages setup

1. Upload the **contents** of this ZIP to your repository root, including `.github/workflows/` and `tools/` (hidden `.github` folder is required).
2. Under **Settings → Pages**, choose **GitHub Actions** as the build and deployment source. Do not choose "Deploy from a branch" for this scheduled publishing method.
3. Open **Actions → Publish Roseville schedule → Run workflow** to perform the initial deployment. The workflow then runs twice per hour (GitHub scheduled Actions may run late).
4. If the public source cannot be fetched from GitHub's runner, the site still deploys and the page reports that an update is unavailable. The file isn't fabricated or overwritten with old data.

A regular browser may block direct cross-origin requests (CORS). The GitHub Pages workflow is intended to support reliable same-origin loading without bypassing any authentication. No credentials are required or stored. Please respect data provider terms.

The `published.html` page provides a standalone published viewer; `index.html` is the main site. Club crests load externally where available. Any playoff slot is conditional and not a confirmed Elk Grove match.
